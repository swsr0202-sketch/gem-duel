# 寶石切割 PK：線對稱大挑戰 💎

國小五年級數學「線對稱圖形」互動遊戲，練習繪製線對稱圖形。

## 玩法
- 藍色是題目半顆寶石，黃線是對稱軸，點空格畫出粉紅鏡像。
- 支援拖曳連塗、對折檢查、清除、切割送出自動判分。
- 模式：練習 / 單人 PK 電腦 5 回合 / 雙人輪流 PK。
- 軸向：左右、上下、兩種斜線，第 5 回合雙軸魔王關分數 x2。

## 本機開啟
直接用瀏覽器開啟 `index.html` 即可。

## 線上部署（GitHub Pages）
Settings → Pages → Deploy from branch → main / root，網址為 `https://<帳號>.github.io/<repo>/`。
